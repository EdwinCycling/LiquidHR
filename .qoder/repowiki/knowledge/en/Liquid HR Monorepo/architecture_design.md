The root is an npm workspaces monorepo: `package.json` declares `apps/*` and `packages/*` as workspace members, and root scripts (`dev`, `build`, `lint`, `test`, `type-check`, `migrate`) delegate to child workspaces. The deployable application is `@liquid-hr/hr-suite` (a Next.js app), which is both the default target of `npm run dev` and the sole build target in `vercel.json`. Shared code lives under `packages/*` and is consumed by apps through workspace references. Documentation and decision records are centralized under `docs/`, while AI-agent behavior is governed by `AGENTS.md` and the release-loop defined in `LOOPS.md`.
