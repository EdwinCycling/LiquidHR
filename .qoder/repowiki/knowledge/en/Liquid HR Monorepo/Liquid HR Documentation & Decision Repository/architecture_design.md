Pure Markdown documentation repository with no executable code. Five top-level subdirectories each serve a distinct responsibility: `architecture/` holds canonical blueprints (BLUEPRINT.md, ENVIRONMENT_AND_AI_RULES.md, LOGIC_AND_WORKFLOW.md, UI_FLOW_BLUEPRINT.md, LIQUID_DISPLAY_DOCUMENTATIE.md) defining schema, API, auth, project structure, environment rules, business workflows, UI flows, and the Liquid Display engine; `requirements/<domain>/` groups domain-scoped requirement documents by feature area (absence, authorization, chatbot, core-hr, custom-fields, documents, employment, leave, liquid-display, multitenancy, organization, reports, settings), each tagged with LEIDEND/CONCEPT/VERVANGEN status and implementation state; `decisions/` stores ADR-#### (technical) and FDR-#### (functional) decision records following a fixed template enforced by `decisions/README.md`; `delivery/` provides chronological change logs and implementation status serving as the single source of truth for current vertical slices; `superpowers/` contains dated plans and design specs paired by date prefix used for execution planning before requirements are finalized. The root `docs/README.md` enforces a mandatory reading routing matrix dictating which documents must be consulted per type of change. Dependency direction is strictly outward — this module contains only specifications that the rest of the repository implements.
