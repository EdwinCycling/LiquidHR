# LiquidHR brand asset pack

Inhoud:

- `branding/`
  - `logo-horizontal.png` — hoofdlogo, transparant
  - `wordmark.png` — woordmerk, transparant
  - `mark.png` — icoon-only, transparant
  - `app-icon.png` — vierkante app-icon
  - `svg/` — SVG-versies van de hoofd-assets
  - `transparent/` — expliciete transparante varianten
  - `white-background/` — versies op witte achtergrond

- `web/`
  - `favicon-16x16.png`
  - `favicon-32x32.png`
  - `favicon.ico`

- `pwa-mobile/`
  - `icon-192.png`
  - `icon-512.png`
  - `apple-touch-icon.png`

Aanbevolen gebruik:

- Header / login: `branding/logo-horizontal.png`
- Smalle header of footer: `branding/wordmark.png`
- Favicon / kleine badges: `branding/mark.png`
- PWA / mobile launcher: `branding/app-icon.png`

Opmerking over SVG:

De SVG-bestanden zijn verpakt als SVG-assets op basis van de goedgekeurde PNG-masters, zodat je ze direct in webprojecten kunt gebruiken. Als je later een volledig native vector brand pack met handmatig opgebouwde paden wilt, kan dat als vervolgstap nog verfijnd worden.
