## PRODUCT DECISIONS

- WvP tasks are a foundation for deterministic signals and human follow-up, not legal advice or an automatic legal-deadline verdict.
- `absence_cases`, `absence_spells` and recovery-window lifecycle have separate KPI meanings; this is documented in [`FDR-0010`](../../../decisions/FDR-0010-verzuim-kpi-eenheden.md).
- The new WvP task API is canonical and human-confirmation-aware. This ABS02 slice does not add an automatic legal conclusion or an unrestricted direct task editor.

## LESSONS/PATTERNS

- For Supabase helper changes, verify the canonical function signature against the live schema before writing a migration. A forward repair is safer than replaying or rewriting an applied migration.
- Direct DML revocation must be paired with positive canonical workflow wrappers, RLS readback, grants readback and regression tests; UI-only hiding is not a security boundary.
- For multi-employment absence KPIs, aggregate at employee level before calculating the denominator. Summing percentages or selecting the last employment produces materially wrong results.
- ACT-AS transport should be cookie-only for browser flows, with persisted revocable scope and no URL/body bearer token.
