## LESSONS/PATTERNS

- Any filter that changes visible rows and export output must be applied from the canonical service query before KPI derivation; a client-only filter is not an acceptance-safe implementation.
- Scope checks must cover every returned source row and placement, not only the first row used to infer a dataset’s scope.
- CSV quoting is not spreadsheet-injection protection; formula-prefix neutralization belongs in the shared cell writer and needs report-specific regression coverage.
