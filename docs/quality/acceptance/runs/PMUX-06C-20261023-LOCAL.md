## Scheduler: statisch gecontroleerd

De bestaande `vercel.json` plant `/api/cron/process-automation-reminders` iedere minuut in UTC. De openbare Vercel-planregels vereisen Pro of Enterprise voor dit interval; Hobby ondersteunt slechts dagelijks met uurprecisie. Het projectplan is niet uit een account gecontroleerd.

`CRON_SECRET` wordt server-side gelezen; ontbrekend geeft HTTP 503 en onjuist Authorization-token geeft HTTP 401. De route wordt door Vercel alleen op een Production deployment als cronjob geactiveerd; er is hier geen remote setting of deployment gewijzigd. Mislukte invocaties worden niet automatisch door Vercel herhaald. Controleer Cron Jobs → View Logs voor de route en de bestaande queue retry/dead-letterstatus. De worker verwerkt maximaal vijf jobs per run: 300 per uur is alleen een theoretisch plafond bij één geslaagde run per minuut, geen gemeten capaciteit. Monitor due READY/RETRY-aantallen, oudste `available_at`, DEAD_LETTER, looptijd en invocationfouten; remote backlogmetingen/alerts ontbreken.

Bronnen: [Cron usage and pricing](https://vercel.com/docs/cron-jobs/usage-and-pricing) en [Cron management, security and errors](https://vercel.com/docs/cron-jobs/manage-cron-jobs), geraadpleegd 23 oktober 2026.
