## Lessons / patterns

- `CONVERGENCE_REQUIRED` is zichtbaar in de migration- en routecontracten; een niet-toegepaste remote schemawijziging wordt niet als hosted succes gerapporteerd.
- First-admin bootstrap schrijft alleen hash/idempotency/auditmetadata; token en raw source data blijven buiten logs, public response en staging.
- Contextcookies zijn hints, geen autorisatie. Bij een niet-eenduidige of vervalste combinatie volgt expliciete keuze of fail-closed denial.
