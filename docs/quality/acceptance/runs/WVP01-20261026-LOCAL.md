**Herstelstrategie:** een fout vóór COMMIT rolt de migration volledig terug. Na succesvolle toepassing wordt geschiedenis niet verwijderd en worden historische migrations niet herschreven. Bij een defect volgt een afzonderlijke forward-only correctiemigration. Een code-terugval kan de voorgaande applicatiecode gebruiken terwijl additieve tabellen en audit behouden blijven; dit autoriseert geen deployment. De deferred proces-FK laat uitsluitend binnen de starttransactie een tijdelijke referentie toe en eist bij COMMIT de echte kernelinstantie; een mislukte start laat geen traject/evidence achter.
